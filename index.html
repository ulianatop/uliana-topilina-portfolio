About me

I am a Computing and Software Development student at Lake Washington Institute of Technology focused on building full-stack web applications. Through coursework and projects, I am building experience with JavaScript, React, Node.js, Express, REST APIs, SQL, MySQL, Python, Java, and HTML/CSS.

This is something I want to keep in mind as I continue learning and growing in software development.

Full-stack team project

Montessori Student Attendance Tracker

This is a full-stack team project completed for a Software Engineering course. Our six-person team built a student attendance system for Northern Lights Montessori School. Authorized adults can check students in and out using a PIN or QR code, with attendance records connected to student and adult information.

My main contributions included designing the MySQL database schema and ERD and implementing REST API functionality for adding students and authorized adults. I also connected the administrator login form to backend credential verification, updated QR code handling, improved the UI layout and readability, and created and maintained project documentation. After the course, I fixed remaining bugs and configuration issues and added automated test and build checks with GitHub Actions.
