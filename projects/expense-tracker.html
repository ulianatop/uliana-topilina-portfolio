Expense Tracker Web App

This is a full-stack coursework project that helps users track personal expenses by category. The app includes user registration and login, password hashing, token-based access, category management, and expense records that belong to the logged-in user. It was built with a JavaScript frontend, a custom Node.js backend, and a MySQL database.

JavaScript Node.js MySQL HTML/CSS JWT REST API bcrypt Vitest GitHub Actions

Problem and Objective

Many people need a simple way to track their spending without using a complicated finance app. The objective of this project was to build a practical app with clear user flows for registering, logging in, adding expenses, viewing records, organizing categories, and managing user-specific data.

Technical Implementation

The project uses a JavaScript frontend, a custom Node.js backend, and a MySQL database. REST API routes support user authentication and CRUD operations for expenses and categories. Passwords are hashed with bcrypt, while JWT authentication and backend middleware protect user-specific data. Vitest covers client, server, database, authentication, routing, and API behavior, with GitHub Actions running the tests automatically.

Challenges and Solutions

One of the main challenges was adding multiple-user support so each user could have their own expenses and categories. The solution was to add registration and login, hash passwords with bcrypt, create JWT tokens after login, and use backend checks so each user could only access their own records.

Results and Learning

The completed app supports user registration and login, secure password storage, JWT-protected requests, and user-specific expense and category management. Users can add, view, edit, and delete both expenses and categories.

Through this project, I strengthened my understanding of how frontend state, backend APIs, MySQL data, authentication, middleware, and automated tests work together in a full-stack application. Building the backend without a framework also helped me understand the functionality that frameworks usually provide.
