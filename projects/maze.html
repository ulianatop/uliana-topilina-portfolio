C++ algorithm project

Maze Generator and Solver

This is a C++ coursework project that generates a random maze and searches for a path from the top-left entrance to the bottom-right exit. OpenCV visualizes the maze generation and solving processes as they run.

C++ OpenCV CMake Depth-First Search Backtracking Object-Oriented Programming

Problem and Objective

The objective was to create a grid-based maze, remove walls to produce randomized paths, and then find a valid route from the entrance to the exit. The program also needed to display both processes visually so the algorithm's progress could be followed.

Technical Implementation

The project uses Square, MazeSquare, and Maze classes to represent the grid, walls, visited cells, and solution path. The maze is stored as a dynamically allocated two-dimensional grid of MazeSquare objects.

Stack-based traversal and randomized selection of unvisited neighboring cells are used to generate the maze. A depth-first search with backtracking then explores open paths and removes unsuccessful cells from the displayed solution. OpenCV draws and updates the maze as the program runs, while CMake handles the build configuration.

Challenges and Solutions

One challenge was removing unsuccessful paths from the visualization while preserving and displaying the final solution.

I addressed this by tracking visited cells and solution-path cells separately. When the solver reaches a dead end, it backtracks using the stack and removes that cell from the displayed path. This leaves only the successful route once the exit is reached.

Results and Learning

The completed program generates a randomized maze, displays the generation process, searches for a route to the exit, and visualizes the final solution.

Through this project, I strengthened my understanding of depth-first search, backtracking, stack-based traversal, object-oriented programming, inheritance, polymorphism, pointers, dynamic memory, and two-dimensional grid management in C++.
